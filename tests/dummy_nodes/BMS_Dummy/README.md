# BMS_Dummy — BMS(HV) 대역 노드

BQ76972 기반 HV 배터리 BMS **2팩(BOT / TOP)** 이 보내는 CAN 프레임을 생성한다.
공통 배선·클럭·코드 삽입 방법은 상위 [`../README.md`](../README.md) 참조.

---

## 1. 송신 프레임

**[주의] BMS 프레임은 전부 빅엔디안 정수다.** 수신측이 `__REV16`/`__REV` 로
뒤집어 읽으므로 `be16()` / `be32()` 만 쓴다. MPPT·Motor 의 `lef()` 를 잘못 쓰면
값이 완전히 뒤집혀 해석된다.

### PRIMARY — 100 ms

| ID | 내용 |
|---|---|
| 0x040 / 0x044 | GlobalFault u32@0 · BattStatus u16@4 · Alarm u16@6 |
| 0x041 / 0x045 | Stack_V u32@0 [mV] · Pack_V u32@4 [mV] |
| 0x042 / 0x046 | PackCurrent i16@0 · MaxCell u16@2 · MinCell u16@4 · Temp i16@6 |
| 0x043 / 0x047 | SOC u16@0 [‰] · byte2–7 예약(0) |

앞쪽이 BOT, 뒤쪽이 TOP 이다.

> **[주의] TOP 팩의 PackCurrent(0x046@0)는 수신측이 읽지 않는다.**
> 두 팩이 직렬이라 전류가 같기 때문이다. 더미는 실물과 동일하게 값을 채워
> 보내지만, 지상국에 나타나지 않는 것이 **정상**이다.

### 레거시 FET 상태 — 100 ms

| ID | 내용 |
|---|---|
| 0x123 / 0x223 | FET_status · CHG · DSG · PDSG (u8 × 4) |

이 2개만 0x1xx / 0x2xx 대역이다. 수신 필터(0x040–0x34F) 안에 들어간다.

### DETAIL — 500 ms

| ID | 프레임 수 |
|---|---|
| 0x048 + 0..8 (BOT) | 9 |
| 0x051 + 0..8 (TOP) | 9 |

셀 전압, 상세 온도, 쿨롱 카운터 등.

> **[주의] 오프셋 +8 프레임은 실물이 DLC 6 으로 보낸다.**
> 수신측은 이 사실을 알고 `rx_data` 를 매 프레임 0으로 지운 뒤 읽는다
> (`can_receiver.c` 의 `memset(rx_data, 0, ...)`). 더미는 DLC 8 고정으로
> 보내므로 이 경로가 실물과 완전히 같지는 않다. DLC 짧은 프레임의 잔여
> 바이트 오염을 검증하려면 `wsc_can_send()` 의 `hdr.DLC` 를 임시로 6 으로
> 낮춰서 시험해야 한다.

### SD_ONLY — 1 s

| ID | 프레임 수 |
|---|---|
| 0x05A + 0..18 (BOT) | 19 |
| 0x06D + 0..18 (TOP) | 19 |

CUV / COV / 셀 밸런싱 비트맵 / Safety / PF 상태 등, 사고 후 진단용 신호다.

`bms_dummy.c` 상단의 `BMS_DUMMY_SEND_SDONLY` 로 이 그룹만 끌 수 있다.
버스 부하를 낮춰 다른 노드 문제를 격리할 때 쓴다.

## 2. 버스 부하

최대 66 프레임/초 구성이며, 1초 경계에서 PRIMARY·DETAIL·SD_ONLY 가
겹치는 순간이 가장 무겁다. 500 kbps 에서 8바이트 표준 프레임은 약 260 µs 이므로
**순간 최대 약 66 x 260 µs ≈ 17 ms** 구간이 발생한다.

이건 의도된 것이다. 송신 보드의 FDCAN RX FIFO0 은 **HAL 하드코딩 3칸 고정**
(`SRAMCAN_RF0_NBR = 3U`, 설정 불가)이라, 이 버스트가 바로
`RX_FIFO0_MESSAGE_LOST` 를 유발할 수 있는지 확인하는 것이 이 더미의 핵심 목적
중 하나다.

---

## 3. 값의 성격

정수 삼각파 기반이라 최소/최대 도달 지점이 눈으로 확인된다.
SOC, 셀 전압, 온도가 서로 독립적으로 움직이므로 **물리적 정합성은 없다**
(Motor_Dummy 만 물리 모델을 돌린다). 지상국의 파싱·표시 검증이 목적이지
주행 시나리오 재현이 목적이 아니다.

## 4. 대조 기준

- 수신측 파서: `Core/Src/can_receiver.c`(저장소 루트 기준) 의 `CAN_StoreBms*`
- 원본 규격: `CAN DATA/BMS_CAN_ID_명세_최신_PR31.xlsx`

> 2026-08 에 BMS 팀과 **비트레이트 불일치** 이슈가 있었다(커밋 65ee2d9).
> 실차 연결 전 BMS 쪽 설정이 500 kbps 인지 반드시 재확인할 것.

# MPPT_Dummy — Elmar Best MPPT 4대 대역 노드

태양광 MPPT **4대**가 보내는 CAN 프레임을 한 보드에서 생성한다.
공통 배선·클럭·코드 삽입 방법은 상위 [`../README.md`](../README.md) 참조.

---

## 1. 송신 프레임

**[주의] MPPT 프레임은 전부 리틀엔디안 float(IEEE754 4바이트 × 2) 다.**
BMS(빅엔디안 정수)와 정반대이므로 `lef()` 만 쓴다.
유일한 예외가 `base+5`(Status) 로, 이것만 u8 비트필드다.

베이스 ID: **0x310 / 0x320 / 0x330 / 0x340** (유닛 1–4)

| 오프셋 | @0 | @4 | 주기 |
|---|---|---|---|
| +0 | Input_Voltage [V] | Input_Current [A] | 200 ms |
| +1 | Output_Voltage [V] | Output_Current [A] | 200 ms |
| +2 | Mosfet_Temp [℃] | Controller_Temp [℃] | 1 s |
| +3 | Aux 12V [V] | Aux 3V [V] | 1 s |
| +4 | Max_Output_Voltage [V] | Max_Input_Current [A] | 1 s |
| +5 | **u8 비트필드** (아래) | | 1 s |
| +6 | PowerConn_Voltage [V] | PowerConn_Temp [℃] | 1 s |

`+5` Status 프레임 바이트 배치:

```
d[0] RX err cnt   d[1] TX err cnt   d[2] TX overflow   d[3] error flags
d[4] limit flags  d[5] mode         d[6] reserved      d[7] test counter
```

총 **4 유닛 × 7 프레임 = 28 프레임**을 보낸다. 실물 MPPT 가 보내는 전 프레임을
그대로 보내야 버스 부하와 필터 동작이 실차와 같아지므로, 수신측이 값을 취하지
않는 프레임도 전부 송신한다.

---

## 2. 4대의 위상을 어긋내는 이유

`phase_of(unit) = seq + unit × 37` 로 유닛마다 파형 위상을 다르게 준다.

4대가 똑같이 움직이면 지상국에서 **유닛 구분이 안 된다** — 그래프 4개가 완전히
포개져서, ID 라우팅이 잘못돼 한 유닛 값이 다른 유닛 칸에 들어가도 눈치챌 수 없다.
위상을 어긋내면 겹침이 사라지고, 결과적으로 구름 그림자가 어레이를 훑고 지나가는
실제 상황과도 비슷해진다.

---

## 3. 입출력 전력 정합성

출력 전류를 독립 파형으로 만들지 않고 **입력 전력에서 유도**한다.

```
out_i = in_v × in_i × 0.97 / out_v
```

효율 97 % 로 전력이 보존되므로, 지상국에서 **입력 전력 > 출력 전력** 관계가
깨지면 파싱이나 스케일 오류가 있다는 뜻이다. 독립 난수였다면 알 수 없는 정보다.

값 범위: 입력 60–95 V / 0.2–9 A (어레이측), 출력 340–400 V (배터리측).

---

## 4. sticky OR 검증용 오류 비트

`+5` 프레임의 `d[3]`(error flags)에 **60틱마다 한 틱만** `0x40` 을 세운다.

수신측은 error flags 를 sticky OR 로 누적하고 스케줄러가 패킷에 실은 직후
클리어한다. DETAIL 주기가 길어서 "잠깐 떴다 사라지는 비트"를 놓치지 않는지가
검증 포인트다. 이 비트가 지상국에 나타나지 않으면 sticky OR 경로가 깨진 것이다.

---

## 5. 누적 발전량은 보내지 않는다

**실물 MPPT 는 누적 발전량을 보내지 않는다.** 순시값(전압·전류)만 있고,
누적은 수신측에서 적분해야 하는 값이다.

더미도 동일하게 보내지 않는다. 지상국에 누적 발전량이 필요하면 수신측 적분
로직을 확인할 것이며, 더미에 필드를 추가해서 해결할 문제가 아니다.

## 6. 대조 기준

- 수신측 파서: `Core/Src/can_receiver.c`(저장소 루트 기준) 의 `CAN_StoreMppt()`
- 원본 규격: `CAN DATA/MPPT_Elmar Best datasheet.pdf` §8.5

> 4번째 유닛(0x340)은 2026-08 증설분이다 (`0x300 + 4 × 0x010`).
> 수신 필터 상한이 0x34F 이므로 5번째 유닛(0x350)을 추가하려면
> 송신 보드의 `CAN_FILTER0_ID2` 도 함께 넓혀야 한다.
